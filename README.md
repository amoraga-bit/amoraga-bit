### 👨‍🏫 Sobre mí

Soy un educador dedicado a formar a la próxima generación de desarrolladores de software en el nivel de **Educación Media** (High School). Mi enfoque combina los fundamentos de la ingeniería de software con herramientas modernas y flujos de trabajo de la industria, como **GitHub Classroom**, para preparar a los estudiantes para el mundo real. Practico activamente lo que enseño — cada repositorio público de este perfil es parte de mi propio proceso de actualización técnica gracias a MINEDUCYT y Kodigo.

**Creando el futuro de la tecnología, un estudiante a la vez.**

### 📚 Mi Enfoque Educativo

Utilizo **GitHub Classroom** como la columna vertebral de mis cursos para simular un entorno de desarrollo profesional.

- **Pizarras Educativas:** Clases visuales que conectan la teoría (diagramas de flujo) con la práctica (código), como se ve en mi banner.
- **Aprender Haciendo:** Proyectos prácticos y asignaciones basadas en repositorios.
- **Colaboración:** Fomento el uso de Pull Requests y revisiones de código entre compañeros.
- **Automatización:** Introducción básica a CI/CD para validar la calidad del código de los estudiantes.

### 📂 Proyectos Destacados

Repositorios donde documento mi propia práctica técnica fruto de las capacitaciones implementadas por Kodigo como parte del Bootcamp Transformación Digital para la Docencia Técnica — mismas que espero llevar al aula.

#### 🔐 [M6Act2 — API REST con JWT, bcrypt, roles y Swagger](https://github.com/amoraga-bit/M6Act2_API_REST_JWT_Swagger)
Sistema de reservaciones de restaurante con autenticación JWT, encriptación bcrypt, control de acceso por roles (cliente/admin), validación de disponibilidad, documentación Swagger y despliegue en Railway + Neon (PostgreSQL).
`Node.js` · `Express` · `PostgreSQL` · `JWT` · `Swagger` · `Railway`

#### 🌐 [M6Act1 — API REST con Express.js](https://github.com/amoraga-bit/M6Act1_API_REST_EXPRESS_JS)
API REST construida desde cero con Express, base para los conceptos de rutas, middlewares y estructura backend que luego se amplían en el proyecto de autenticación.
`Node.js` · `Express`

#### 🗄️ [MD5 — SQL: CRUD y JOINs](https://github.com/amoraga-bit/MD5_Act_Evaluada)
Actividad evaluada sobre manipulación de datos en SQL — lectura, escritura y relaciones entre tablas como base de todo desarrollo backend profesional.
`SQL` · `PostgreSQL`

#### 🎨 [HTML + CSS — Página semántica con formulario](https://github.com/amoraga-bit/htmlcss)
Página web temática de tecnología aplicando HTML5 semántico, formulario funcional y estilos visuales base.
`HTML5` · `CSS3`

#### 🐳 [React + Docker](https://github.com/amoraga-bit/react-docker)
Práctica de contenerización de una aplicación frontend en React.
`React` · `Docker`

#### 🚀 [Repositorio-FD — Flujo de trabajo con Git/GitHub](https://github.com/amoraga-bit/repositorio-FD)
Dominio del flujo de trabajo con Git y GitHub, documentación técnica y pruebas de estructura en Markdown, apoyado con Antigravity.
`Git` · `GitHub` · `Antigravity`
